# ProjectX public application

Read README.md first. This repository contains the public prototype, not private project records.

- Source lives in platform/. Root index.html is generated by `npm run build`.
- Run `npm test` after changes and rebuild before publishing.
- Keep the minimal design, centered table headings and no routine system notifications.
- Cargo names are English. Do not guess cargo classifications or shipment SF.
- Preserve stable cargo IDs, user edits, local-storage migration and financial rounding invariants.
- The final internal voyage decision belongs to the chartering head; the tool is not technical approval.
- Do not add original vessel identities, private files, credentials or user calculations.
- Update README.md when behavior, data coverage or limitations change.
